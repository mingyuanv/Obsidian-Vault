
# 列出所有仓库（显示变更状态）
python tools/git_sync.py -l

# 仅提交有变更的仓库
python tools/git_sync.py -v

# 指定单个仓库提交
python tools/git_sync.py -r XGRIDS -v

# 指定单个仓库提交并强制推送
python3 tools/git_sync.py -r code-notes -p -f

# 强制提交推送（即使无变更）
python tools/git_sync.py -f -p -v

# linux 系统用python3   python3 tools/git_sync.py -p  就行,code-notes随便做一个修改吧。

| 参数 | 简写 | 作用 | 说明 |
| :--- | :---: | :--- | :--- |
| --push | `-p` | 提交并推送 | 默认情况下脚本只执行 `git commit`。加上此参数后，会额外执行 `git push` 将代码推送到远程仓库。 |
| --force | `-f` | 强制提交 | 默认情况下，如果没有文件变更，脚本会跳过。加上此参数后，即使没有变更也会尝试执行提交操作。 |
| --repo | `-r` | 指定仓库 | 指定只同步某一个仓库。后面需要跟上仓库的名称（如 `主库`、`XGRIDS` 等）。 |
| --list | `-l` | 列出仓库 | 显示所有已配置的仓库路径，并检测它们当前的 Git 状态（是否有变更）。 |
| --verbose | `-v` | 详细输出 | 在命令行中打印详细的同步结果（成功或失败的具体信息）。 |
